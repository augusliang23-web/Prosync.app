ENTERPRISE ARCHITECTURE SPECIFICATION

ProSync AI 企業專案數據治理與 C-Suite 決策閉環系統

本系統設計宗旨在於消除企業「基層 PM 週報資訊斷層」與「高層決策無記錄」之痛點。透過 **Google Gemini 3.6 Flash** 雙向數據賦能，將口語化週報自動轉換為具備 ROI 剖析的 Executive Briefing，並建立永久可審計的 **Decision System of Record (高層決策拍板履歷)**。

前端：React 18 + Vite + Tailwind CSS 後端：Express.js RESTful API + Node.js AI 核心：Google Gemini 3.6 Flash (@google/genai) 狀態持久化：Local Storage / Cloud SQL / Firestore

1 產品階層架構 (Product Layer Architecture)

分為前端展示層、後端服務閘道層、AI 智能運算核心層、以及企業資料與持久化層

4-Tier System
Layer 1: User Experience

前端視圖與互動層

基於 React 18 SPA 構建，包含雙重視角 (C-Suite 戰略導向 / PM 實務營運導向)。

  • ExecutiveDashboard: 全公司 ROI 與指標中心
  • ExecutiveBriefingCard: 高層週報與 AI 警報
  • DecisionCaptureModal: 高層拍板授權與預算核撥
  • OrgStructureView: 人力跨部門借調看板
Tech: React 18, Vite, Tailwind CSS, Lucide
Layer 2: Service Gateway

Express 後端 API 閘道

負責阻絕前端暴露 API Key，處理 Prompt 工程、資料驗證與跨域防護。

  • /api/ai/executive-summary: AI 簡報生成
  • /api/ai/qa: 戰略問答秘書控制
  • /api/ai/polish-update: PM 週報 AI 潤飾
  • /api/health: 系統與 API 金鑰健康診斷
Tech: Node.js, Express 4.x, TypeScript
Layer 3: AI Engine

Gemini 3.6 Flash 運算核心

Google 高速 Multimodal LLM，透過廣泛 Context Window 進行強大分析。

  • Structured JSON Output: 嚴格 Schema 契約
  • Domain Instruction: C-Suite COO 經驗角色扮演
  • Risk Extraction: 自動抽取 AT_RISK 與阻礙根因
  • Action Recommendation: 產生可具體執行對策
SDK: @google/genai (gemini-3.6-flash)
Layer 4: Data & Audit Log

資料與永久履歷日誌層

管理專案狀態、財務支出、成員組織庫與永久不可竄改高層決策紀錄。

  • Projects Entity: 健康度、預算、里程碑
  • Decision Records: 拍板編號 DEC-xxx、核准資金
  • Traceable Action Items: 責任人、履約死線
  • Org Requests: 跨部門借調申請單據
Storage: LocalStorage / Cloud SQL / Firestore

2 端到端資料流向 (End-to-End Data Pipelines)

四大核心情境的完整資料傳遞流程與轉譯階段

管道 A：PM 週報輸入 ➔ AI 專業潤飾 ➔ 送審與寫入歷史

Latency: ~1.2s
STEP 01

PM 輸入草稿

PM 於 UI 填寫口語化、非格式化之本週成就與阻礙障礙。

STEP 02

POST /api/ai/polish-update

打包傳至 Express，注入量化點陣化專屬 Prompt 指令。

STEP 03

Gemini 3.6 Flash 處理

模型解析動詞、數據指標，並按照 JSON Schema 格式輸出專業點陣文字。

STEP 04

更新 UI & State Sync

潤飾內容回填輸入框，PM 確認後點擊送出，儲存至專案最新週報演進鏈。

管道 B：全公司專案進度 ➔ 高層 AI Briefing 綜合研判 ➔ 儀表板渲染

Latency: ~2.1s
STEP 01

高層觸發生成

點擊「重新生成 Executive Briefing」或定期自動背景排程。

STEP 02

POST /api/ai/executive-summary

傳送全公司所有 Projects 數據陣列 (包含健康度、預算支出與最新週報)。

STEP 03

JSON Schema 結構提取

Gemini 依據 Schema 產出摘要、Critical Blockers、Top Wins 與跨部門戰略建議。

STEP 04

財務與警報併合

後端計算精確總預算、實際支出與完成度後，回傳前端進行高層檢視。

管道 C：高層點擊拍板 ➔ 產生唯一 DEC 履歷 ID ➔ 自動授權與行動項追蹤 (Closed-Loop)

Latency: Instant (Local/Database Transaction)
STEP 01

點擊「進行高層拍板」

於 Briefing Card 臨界風險欄位點擊按鈕，開起授權 Modal。

STEP 02

輸入決策與授權金額

主管選擇批示類別 (追加預算/人力支援/時程延後)，輸入決策者姓名與批示內容。

STEP 03

生成 DEC-xxx 交易紀錄

系統產生唯一交易 ID、防竄改時間戳記，並衍生關聯 Action Items 可追蹤任務。

STEP 04

自動更新專案預算與閉環

若包含追加預算，系統自動同步加算至專案 `totalBudget`，簡報標示為「已拍板」。

管道 D：主管問答諮詢 ➔ 傳送 Context ➔ Gemini 戰略秘書剖析

Latency: ~1.5s
STEP 01

主管提問或預設快捷鍵

主管輸入疑問 (例如「哪幾個專案預算超標需要關注？」) 或點擊 AI 建議案例。

STEP 02

POST /api/ai/qa Context 注入

將問題連同全公司所有專案數據與最新 Briefing 摘要一同打包傳至伺服器。

STEP 03

Gemini 戰略顧問推論

模型先給出直接結論，次要說明根本原因，最後列出 3 點具體決策建議。

STEP 04

Markdown 格式精美呈現

前端渲染問答卡片，支援一鍵複製與延伸問題追問。

3 核心模組功能與規格細節 (Module Functional Specification)

前端 7 大模組功能清單、操作邊界與核心職責

模組 1: C-Suite 戰略儀表板 (Executive Dashboard)

Core Portal

為 CEO/COO 打造的高總覽視圖。整合整體投資報酬率 (ROI)、預算執行率 (Budget Utilization)、全公司健康度分佈 (ON_TRACK / AT_RISK / DELAYED)，以及跨部門健康度柱狀圖。

關鍵功能特點：
  • 一鍵切換多國貨幣 (TWD / USD / EUR) 與動態匯率即時折算
  • 過濾器：依據部門 (研發部/IT/行銷/營運) 與健康狀態交叉篩選
  • 自動警報：若專案落後，自動突出顯示紅字風險提示

模組 2: 高層 AI 週報與觸發器 (Executive Briefing Card)

AI Engine

展示 AI 產出的全公司綜合週報。將全公司數十份複雜週報蒸餾為「10 秒讀懂」的關鍵對策、高風險阻礙清單、Top Wins 與跨部門戰略建議。

關鍵功能特點：
  • 【拍板觸發器】：直連高層決策 Modal，秒級完成授權與資金核可
  • 一鍵複製週報摘要文字 (貼至 Email 或 Line/Slack 群組)
  • 「諮詢 AI」預設按鈕：自動帶入當前阻礙並開啟 QA 戰略秘書

模組 3: 高層決策履歷與行動庫 (System of Record)

Audit System

解決企業「口頭交辦無憑無據、過後無法追責」之盲點。將高層每一次的追加預算、派員支援、批示決策永久記錄並賦予唯一交易 ID。

關鍵功能特點：
  • 決策歷程標竿庫：支援依專案、決策者、批示類型查詢搜尋
  • 行動項 (Action Items) 狀態追蹤：未開始 ➔ 執行中 ➔ 已完工
  • 審計等級記錄：防竄改時間戳記、額外核准資金明細

模組 4: 組織架構與人力調動看板 (Org Structure)

Resource Mobility

可視化部門樹狀圖與跨部門人力支援借調 (Mobility Requests)。當特定專案面臨技術瓶頸時，PM 可直接申請跨部門專家調動。

關鍵功能特點：
  • 成員技能標籤 (Skills Tags) 與部門歸屬展示
  • 支援借調單申請：借調原因、借調週數、目標專案指派
  • 高層/主管可於 Gateway 一鍵進行跨部門核准與派員

模組 5: 高層審批關卡 Modal (Approval Gateway)

Gateway

集中管理所有待一級主管審核的單據。包含專案里程碑變更、展延申請、預算追加申請以及組織借調申請。

關鍵功能特點：
  • 數字標記 (Badge)：即時顯示待審批單據總量
  • 支援核准 (APPROVE) / 駁回 (REJECT) 並填寫主管批註留言
  • 審批後自動觸發專案時間軸與狀態之更新

模組 6: PM 實務營運入口 (PM Portal & Details)

PM Workspace

專為基層與中階 PM 設計的執行工作台。包含專案卡片圖表、S-Curve 預算曲線、里程碑進度甘特圖、以及週報填寫入口。

關鍵功能特點：
  • 內建【AI 週報潤飾工具】：一鍵將口語草稿轉為數據化點陣文字
  • 歷史週報演進時間軸：完整紀錄歷週專案演化軌跡
  • 發起里程碑展延申請：填寫展延原因與新日期送高層審批
